# School Hub

Você é um desenvolvedor full stack especialista em portais de notícias.

Quero criar um portal moderno para minha escola.

- Notícias

- Blog

- Podcast

- Eventos

- Projetos dos alunos

- Avisos da escola

- Sistema de busca

O público será alunos, professores, pais e visitantes.
